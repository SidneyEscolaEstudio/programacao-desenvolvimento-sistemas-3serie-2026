# Aula 01 — Diagnóstico Python

## Objetivo

Verificar o que a turma já domina em Python antes de avançar para conteúdos de Programação Orientada a Objetos.

## Sequência dos desafios

1. `desafio01_entrada_saida.py` — `input()`, `print()`, variáveis e conversão de tipos.
2. `desafio02_condicionais.py` — `if`, `elif` e `else`.
3. `desafio03_repeticao.py` — laço `for` e `range()`.
4. `desafio04_listas.py` — criação, acesso, inclusão, remoção e repetição em listas.
5. `desafio05_funcoes.py` — criação e chamada de funções.
6. `desafio06_return.py` — funções com `return`.
7. `poo01_classes_objetos.py` — introdução a classes e objetos.
8. `poo02_atributos_metodos.py` — `__init__`, atributos e métodos.
9. `cadastro_alunos.py` — desafio integrador.

## Como trabalhar

Para cada arquivo:

1. Leia o desafio.
2. Tente prever o que o código faz.
3. Execute no terminal.
4. Faça a alteração proposta no final.
5. Mostre o resultado ao professor ou mediador.

Para executar:

```bash
python aula01-diagnostico/desafio01_entrada_saida.py
```

## Checkpoint

Ao final da aula, registre em qual nível você se encontra:

- Fiz sozinho.
- Fiz com pequenos ajustes.
- Fiz com ajuda.
- Tive muita dificuldade.
- Não consegui.

> O diagnóstico não tem como objetivo punir erros. Ele serve para definir o melhor ponto de partida das próximas aulas.
